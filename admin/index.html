자산은 각 계정의 마지막 클라우드 저장을 현재 게임 계산식으로 평가한 가상 화폐(₲)입니다. 저장이 없거나 읽을 수 없는 계정, 삭제된 계정의 저장, 이전 코드 전용 저장은 자산 합계에서 제외합니다.

플레이 시간은 측정 도입 이후 현재 게임 저장에서 화면이 보였던 시간입니다. 일시정지·메뉴 이용은 포함하고, 숨긴 탭·종료·오프라인 경과 시간은 제외합니다. 새 게임·이전 저장 복원 시 수치는 해당 저장을 따릅니다. 측정 전 시간은 미측정이며, 여러 기기의 동시 플레이 시간을 합산하지 않습니다.
